# NovaDock

**Snap POCs to Windows** — one-click deployment platform with premium UI and loop-engineered NSSM automation.

```bash
cd novadock
pnpm install
pnpm db:push
pnpm db:seed
pnpm dev
```

Open http://localhost:3000

## Rename this repository

To match the product name, rename the GitHub repo to **`novadock`**:

**Settings → General → Repository name → `novadock`**

Or with GitHub CLI:

```bash
gh repo rename novadock
```
